Практическая работа №1

Тема работы

Название: Жизненный цикл программного продукта

Цели и задачи

Задачи:

  • Научиться выполнять разработку программного продукта в команде с различным жизненным циклом.
  • Приобрести навыки создания технического задания.
  • Изучить основные модели жизненного цикла.

Теоретические материалы

Представленны в виде лекций

Порядок выполнения работы

Шаг 1. Выберите для вашей группы одну из моделей ЖЦПО и обсудите перечень работ по созданию программного обеспечения для своего варианта.
Шаг 2. Распределите работы между участниками группы, пропишите сроки выполнения.
Шаг 3. Составьте план работу по созданию программного продукта и оформите его в электронном виде.
Шаг 4. Опишите инструменты и технологии, которые будете использовать при разработке.
Шаг 5. Опишите организацию процесса разработки и коммуникабельности:
- управление командой;
- система контроля версий;
- коммуникация;
- документация.

Варианты

Вариант №1:Разработка приложения «Магазин бытовой техники» для работы с внешней базой данных


Разработка приложения «Магазин бытовой техники» для работы с внешней базой данных в системе MS Visual Studio.NET Таблицы базы должны включать поля: Номер продажи, Наименование товара, Страна- производитель, ФИО покупателя, Цена, Дата продажи, ФИО продавца-консультанта (в магазине работают 3 постоянных консультанта- создайте список выбора возможных значений этого поля) и т.д.

Вариант №2:Разработка Windows-приложения «Отдел кадров»

Таблицы базы должны включать поля: Таб номер, Должность (список выбора из нескольких значений), Оклад, ФИО, Дата рождения, Адрес, Телефон, Наличие детей и т.д.
Реализовать возможность сортировки записей по дате рождения сотрудников;
Провести фильтрацию: оставить записи о сотрудниках определенной должности;
Создайте вычисляемые поля в таблице: «Премия» (20% от оклада), «Итого» (оклад + премия).
Определите средний оклад по предприятию;
Ввести несколько собственных процедур обработки и выборки данных, через графики и диаграммы наглядно продемонстрировать результаты.

Вариант №3:Разработка Windows-приложения «Авиакасса»

Примерный перечень полей таблиц: Номер продажи; ФИО покупателя; Пункт назначения, Номер рейса, Дата вылета, Время вылета, Время прибытия, Стоимость билета и т.д
1) Реализовать возможность сортировки записей по датам вылета;
2) Провести фильтрацию данных по пунктам назначения;
3) Создать вычисляемое поле «Таможенный сбор» (5% от стоимости билета)
4) Выбрать информацию о проданных билетах на определенный рейс. Номер рейса вводится пользователем.
5) Ввести несколько собственных процедур обработки и выборки данных, через графики и диаграммы наглядно продемонстрировать результаты.

Вариант №4:Разработка Windows-приложения «Орфография»

Разработать программу «Орфография», которая проверяла бы правильность написания слов в некотором введенном пользователем тексте, сравнивая их со словами из словаря (словарь находится во внешнем текстовом файле). Протестировать с помощью этой программы 10 пользователей.
1) Вывести во внешний файл их результаты (ФИО пользователя; слова, в которых пользователь допустил ошибки; процент слов с ошибками относительно общего количества слов в тексте; оценка (5- если процент ошибочных слов составляет менее 10%, 4- если менее 20%, 3- если менее 30%, иначе - 2.).
2) Вывести фамилии пользователей, получивших данную оценку(выбирается из списка).
3) Определить процент пользователей, получивших 2, 3, 4, 5. Представить результаты наглядно через круговую диаграмму.
