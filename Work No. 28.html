Практическая работа №28

Тема работы

Название: Работа с MySQLWorkbench и взаимодействие с C#.

Цели и задачи

Задачи:

  • изучить основные запросы при работе с базой данных MySQL;
  • изучить синтаксис языка программирования C#;
  • приобрести навыки программирования создания WPF приложений.

Теоретические материалы

Представлены в виде лекций.

Видео выполнения практической работы

Задание

1) Информационная система должна позволять добавлять, редактировать, удалять информацию о компьютерном клубе: наименование, адрес, время работы.
2) Информационная система должна позволять добавлять, редактировать, удалять об аренде игровых компьютеров: дата и время, ФИО клиента.
3) Информационная система должна позволять сохранять информацию в базе данных MySql.

⚠️ Дополнительно

  • Для получения оценки «Хорошо», информационная система должна иметь хороший фильтр, позволяющий сортировать записи.
  • Для получения оценки «Отлично», информационная система должна иметь хороший фильтр, позволяющий сортировать записи, ИС должна иметь систему разграничения доступа клиентов.
