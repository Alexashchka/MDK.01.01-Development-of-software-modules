Тема работы

Название: Изучение методов DELETE

Цели и задачи

Задачи:

  • изучить способы создания Rest API;
  • научиться создавать API при помощи ASP.NET;
  • познакомиться с запросами методов DELETE.

Теоретические материалы

Представлены в виде лекций.

Видео выполнения практической работы

Задание

Шаг 1. Запустить Visual Studio, открыть ранее разработанный проект «API_GET».
Шаг 2. Перейти в файл «Startup», и добавить новую версию документации «Запросы DELETE».
Шаг 3. Запустить приложение, проверить что появилась четвёртая версия документации:

Шаг 4. Загрузить изменения в систему контроля версий, указать комментарий «Настройка приложения документации, добавление версии документации. Фамилия.».
Шаг 5. Самостоятельно прописать методы для удаления данных с типом запроса DELETE. Удаление отдельной записи по ID, и полную очистку таблицы от данных.
