Задачи:

  • изучить основные методы при работе с базой данных;
  • изучить синтаксис языка программирования С#;
  • приобрести навыки программирования создания WPF приложений.

Теоретические материалы

Представлены в виде лекций.

Видео выполнения практической работы

Задание

Разработать RestAPI для приложения курсового проекта по выбранной теме. Проект должен иметь по четыре запроса на каждую CRUD операцию сущности, соответствующего типа:
1) CREATE – POST;
2) READ – GET
3) UPDATE – PUT
4) DELETE – DELETE
Входные параметры необходимо валидировать, а именно проверять на корректность. При работе с базой данных, необходимо использовать EntityFramework.

Разработать сервис авторизации, для идентификации пользователя в системе. При авторизации, клиенту выдаётся токен пользователя, который в дальнейшем используется при выполнении запросов.

Разработать Desktop приложение, обеспечивающее описанный функционал пользователя и администратора в задании на курсовой проект. Desktop-приложение, должно взаимодействовать с RestAPI, посредством запросов HttpClient. Необходимо обрабатывать ошибки, возникающие при взаимодействии модулей.
